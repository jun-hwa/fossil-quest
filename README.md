# 해마루 탐험대

제작: 전준화

세계 지도에서 발굴지를 골라 마인크래프트식 3D 지층을 파고, 조각난 화석을 모아 복원하는 학습 게임입니다.

- 수준: 초등 / 중등 / 고등 (수준별 설명과 탐지기 도움)
- 발굴지 10곳, 단계가 오를수록 화석 조각 수 증가 (1~10조각)
- 화석 도감과 지질 시대 연표

## 실행
`index.html`을 브라우저로 엽니다. (3D 엔진 three.js를 CDN에서 불러오므로 인터넷 연결 필요)

## 조작
- W/A/S/D 이동, 마우스 둘러보기, 왼쪽 클릭 꾹 = 파기, 오른쪽 클릭 = 흙 놓기, Space 점프, R 땅 위로
- 태블릿: 화면 버튼 사용
